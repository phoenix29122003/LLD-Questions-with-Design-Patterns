# LLD Questions with Design Patterns

A collection of Low-Level Design (LLD) interview problems with their solutions, class diagrams, and design patterns.

## Goals
- Practice frequently asked LLD interview questions.
- Understand SOLID principles and OOP concepts.
- Apply appropriate design patterns.
- Write clean, extensible, and maintainable code.

## Topics Covered
- Creational Design Patterns
- Structural Design Patterns
- Behavioral Design Patterns
- Real-world LLD Problems

## Language
Java
